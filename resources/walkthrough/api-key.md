# Connect your Parley account

1. Get your API key from the **Parley Admin Portal** (My Account → API Keys).
2. Run **`Parley: Set API Key`** from the Command Palette (`Ctrl+Shift+P`).
3. Paste the key — it's stored in VS Code's encrypted secret storage, never in a settings file.

Then click **↻** in the chat header to load the model list.
