# Give Parley context

Type `@` in the composer:

| Mention | Attaches |
| --- | --- |
| `@src/app.ts` | a file (add `#10-40` for a line range) |
| `@src/` | a folder listing |
| `@git` | your uncommitted diff vs HEAD |
| `@terminal` | recent terminal commands + output |
| `@codebase` | the most relevant files for your question |
| `@https://…` | a fetched web page |

Also: **`Alt+K`** drops the current selection in as a mention, right-click → **Parley** works from any editor, and you can paste or drag-drop images, PDFs, and audio straight into the composer.
