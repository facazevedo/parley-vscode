# The chat panel

Click the **Parley icon** in the activity bar (or run **`Parley: New Conversation`**).

- The header shows session **tokens · ~cost** and a **context-window ring** — click the ring to compact the conversation.
- **🕘** lists past conversations (this repo or all repos) with rename/archive/delete.
- Press **ArrowUp** in the empty composer to recall previous prompts, terminal-style.
- Prefer a bigger surface? **`Parley: New Conversation in Tab`** opens a parallel chat as an editor tab.
